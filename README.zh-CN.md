# Annotations Everywhere：Obsidian PDF 批注与 Markdown 页边注

[English](README.md) · [简体中文](README.zh-CN.md) · [下载版本](https://github.com/Heptazero/annotations-everywhere/releases) · [反馈问题](https://github.com/Heptazero/annotations-everywhere/issues)

Annotations Everywhere 是开源的 Obsidian 插件。你可以给 PDF 划线、框选公式或图片、添加左右侧边批注，让原文与保留版式的译文共享批注，也可以把 Markdown 脚注显示为可编辑的页边注。批注数据留在自己的库内，不改写 PDF，不要求云账号。

> **先看版本：** 已发布的 **0.50.1** 包含 PDF 批注、共享组、全库管理、按页码转移、原生/手动大纲、Markdown 页边注和库内存储。PDF 双链反向引用与复制模板、颜色语义组、新版划词工具栏、扩展显示转换和标签式设置页已在本地实现，但**尚未发布到 Release 或公开 main 分支**。文档更新不代表这些代码已经上线。请以安装版本的[发布说明](https://github.com/Heptazero/annotations-everywhere/releases)为准；近期新增交互仍待真实电脑和手机验收。

## PDF 划线、公式框选与左右侧边批注

Annotations Everywhere 使用 Obsidian 自带的 PDF 阅读器。批注可以固定在左侧或右侧轨道，也可以自由摆放，或只保留勾画而不显示正文框。

打开 PDF，选中文字，在命令面板搜索 **[PDF]** 添加批注。只想划线时，使用 **[PDF] 仅勾画选区（无批注框）**。没有文字选区时，工具会让你拖出矩形，标记公式、图片或扫描区域。

文字选区保留原文引文；框选只标记位置，**不会 OCR、提取可搜索文字或识别公式**。无需 OCR 也能自己填写批注正文。

**尚未公开的新版工具栏与转换：** 电脑、手机可以分别开启划词后的一排颜色和批注按钮。已有批注可在悬浮注、收起点、自由框和左右侧注之间转换，保留同一条记录的正文、引文、位置、颜色和图层。

**尚未公开的颜色语义组：** 不同阅读语境可以分别设置“论点/证据/疑问”“定义/定理/证明”等配色。每组颜色有独立身份；切组不会重新解释旧批注，移出预设也不删除旧定义。

## 原文与翻译 PDF 共享批注

Annotations Everywhere 支持两份或多份兼容 PDF 共用一套批注，例如英文论文、中文翻译和另一份译本。修改的是共同的数据集合，不是分别复制后互相同步正文。

使用 **[PDF] 添加 PDF 到共享批注组**，搜索并选择另一份文件。共享会检查页数、每页尺寸和旋转方向。已有批注冲突时，可选择合并或只保留一边；替换另一边需要确认。你可以并排打开下一份文件，或保持页码和位置轮流切换组内 PDF。

**版式相同不代表文字位置一定相同。** 共享复用坐标，不做自动翻译、句子对齐或身份识别。增加了封面或插页的文件，可以考虑按页码转移；重新排版的译文仍须检查批注落点。

解除共享使用 **[PDF] 解除共享绑定(当前 PDF 保留批注副本)**。当前 PDF 会留下独立副本，不等于删除批注。

## 批注批量复制、移动与页码映射

在全库管理中选中批注，选择复制或移动，搜索目标 PDF，再填写原起始页、结束页和目标起始页。可以添加多组不重叠的原页码范围。

例如，读过一个 30 页的局部译本，后来换成完整译本：设置 **原 1–30 页 → 目标起始页 11**，会把批注放到目标第 **11–40 页**。复制保留原批注；移动在应用转移后移除所选源记录。

转移按页码映射，并根据目标页面尺寸缩放位置，**不是在另一份 PDF 中自动搜索对应句子**。源 PDF 的文字偏移不会直接套到目标文件。重新排版时要检查位置；已经粘贴进笔记的引用链接不会被批量改写。

## 全库批注搜索、批量管理与未挂载恢复

使用 **[PDF] 打开全库批注管理**，查看哪些文件或共享组有批注、数量和更新时间；搜索内容、按文件夹或独立/共享/未挂载状态筛选，按更新时间排序，展开或折叠。可以选中记录批量删除、复制或移动，也可以跳回 PDF 位置。

当前 PDF 使用 **[PDF] 打开批注列表面板** 或 **[PDF] 搜索当前 PDF 的批注**。列表支持按页码或颜色折叠；图层可让同一条批注属于多个集合，而不复制正文。

PDF 删除或从其他路径恢复后，保留的数据可能显示为“未挂载”。可在管理面板挂载，或使用 **[PDF] 恢复未挂载批注到当前 PDF** 选择旧来源。文件名和页码只是候选线索，不能证明一定属于同一文件。这里恢复的是仍在磁盘上的批注记录，不是找回已删除的 PDF 或已删除的批注数据。

## Markdown 脚注显示为可编辑页边注

使用普通 Markdown 脚注，Annotations Everywhere 会在右侧显示可编辑、跟随滚动的侧注。这与 PDF 批注数据是两条独立工作流。

```markdown
这个结论还有一个适用条件。[^condition]

[^condition]: 在页边显示的补充说明；笔记仍然是普通 Markdown。
```

可以在设置中调整宽度与间距，也可以拖动对齐的边界统一调整。折叠的引用文本不会单独占据页边注位置。无需专有脚注语法。

## PDF 大纲、手动标题与双栏阅读

优先使用 PDF 自带大纲；没有时，可从共享组另一份文件继承。使用 **[PDF] 添加手动大纲标题**，填写标题、层级和起始页，补充缺失目录。批注可在章节范围下折叠；范围延伸到下一个同级或更高层级标题。

**[PDF] 切换批注阅读顺序（单栏 / 双栏）** 调整插件列表中的批注顺序，不改变 PDF 文字层，也不改变原生复制文字的顺序。手动标题不写入 PDF 书签元数据。

## PDF 双链引用与反向链接（未发布）

**以下功能已本地实现，但尚未公开，不属于 0.50.1。** Annotations Everywhere 可复制文字选区或区域链接，再从 PDF 中查看引用它的 Markdown 笔记。

1. 选中文字，使用工具栏链接图标或 **[PDF] 复制选区引用链接**；已有批注与列表也有复制入口。
2. 粘贴进 Markdown 笔记。仅复制不算引用，也不会新增批注或改写笔记。
3. Obsidian 索引链接后，“显示 PDF 引用勾画”会标出对应区域，与已有批注复用同一显示层。
4. 点击区域旁的回箭头，查看来源笔记、引用次数和行号，再选择跳转。

“引用”设置可选仅链接、单行引文或引用块，分别自定义模板和链接显示文字。支持 `{{text}}`、`{{link}}`、`{{file}}`、`{{page}}`，模板必须保留 `{{link}}`；支持真实换行或 `\n`，有预览和恢复默认。原文与 LaTeX 插入后不会再次作为模板解释。

链接保留原生 `selection=` 或兼容 Everything Bilink 的 `rect=`。在译文里复制，指向实际阅读的译文 PDF，不强制跳到英文原文。引用图标可关闭，被引用样式可保持原样、下划线或边框，保留语义颜色。

反链来自笔记链接，不是额外批注记录；明确给引用区域改色或加正文才创建正常批注。删除、移动或重新定位批注不改笔记链接；移除纯引用勾画需要删除对应 Markdown 链接。

这还不是 Everything Bilink 的完整替代：未包含裁剪嵌入预览、公式回填、Markdown 块引用工具和批量改写链接。两个插件并用时只开一边 PDF 引用显示；不迁移或删除 Bilink 数据。详见[集成范围](BILINK-INTEGRATION.md)。

## 电脑与手机同步批注

PDF 批注存为库内文件，默认文件夹为 `.annotations-everywhere/`。也可以在设置中填写其他**库内相对文件夹路径**，电脑和手机填写同一位置。确认同步工具没有忽略该目录，尤其是默认隐藏目录。

文件传输由你已有的库同步工具负责，插件不提供托管同步服务，也不要求账号。支持电脑和移动端代码路径，但真实触控和 PDF 行为仍需在设备上验收。

多设备可能重叠编辑时，可用 **[PDF] 改用可同步的分文件批注**，从旧的 `annotations.json` 迁移到修订文件，减少整库文件冲突。先完成各端同步、备份，并停止旧版写入旧存储。分文件**不保证完全无冲突**，可用 **[PDF] 查看批注同步冲突** 检查。

## 常见问题

### 译文文件必须同名或以 cn_ 开头吗？

不需要。共享时可以手动搜索选择文件；相近名字只帮助排列候选，不代替页面检查。不要求另装命名映射插件。

### 只能绑定两份，还是三份也可以？

可以把三份或更多兼容 PDF 加入同一个共享组，轮流切换；用的是一套批注，不是两两独立复制。

### 勾画后还能补批注、改成侧边注吗？

尚未公开的扩展显示转换支持这样做，并保留同一条记录。不要把它误认为 0.50.1 已有的新转换入口。

### PDF 找回来了，批注就一定自动恢复吗？

不一定。要同时保留批注数据；路径改变后可能需要在“未挂载”里选择来源。页数够用、名字相似都不是身份保证。

### 要 AI API Key，或购买云服务吗？

不需要。插件不内置 AI 服务，不会自动用 AI 阅读、翻译或批注论文。外部 AI 可以帮助起草 Markdown 评论；同步仍由自己选用的工具承担。

## 安装与兼容

上架后可在 Obsidian 的“设置 → 第三方插件 → 浏览”搜索 **Annotations Everywhere**。若目录中还没有，请使用手动安装，不要假定已经上架。

从同一份 [GitHub Release](https://github.com/Heptazero/annotations-everywhere/releases) 下载 `main.js`、`manifest.json` 和 `styles.css`，放入：

```text
<库>/.obsidian/plugins/annotations-everywhere/
```

重启 Obsidian，在第三方插件中启用。最低 Obsidian 版本为 **1.7.2**；升级 Obsidian 后应复查内置 PDF 阅读器的兼容性。

尚未公开的设置 UI 按“常用/引用/外观/管理”分类，支持多词搜索和折叠；数据目录、属性同步和图层在“管理”。这不是对已发布设置页的说明。

## 隐私与范围

插件通过 Obsidian 读取 Markdown/PDF 和链接元数据，将设置、批注保存到库内。复制引用只写剪贴板；插件自身不发网络请求，不收集分析数据。

批注**不会嵌入或导出到 PDF 文件本体**，其他 PDF 阅读器不会显示这套库内记录。它不是 PDF 翻译器、OCR 服务、网页批注扩展或文献管理软件。
